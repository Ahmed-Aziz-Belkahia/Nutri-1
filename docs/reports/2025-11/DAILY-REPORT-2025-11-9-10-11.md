**Major Features Implemented:**

**1. Dashboard Calorie Sync Fix:**
• Fixed dashboard calorie discrepancy - replaced non-existent mealPlan.targetCalories with user profile WHO formula-based goals

**2. Complete Password Reset System:**
• Implemented password reset flow with 6-digit verification codes (15-minute expiry)
• Replaced SendGrid with Nodemailer + Hostinger SMTP (support@nutriai.pl) for reliable email delivery
• Created beautiful HTML email template with gradient design (#0CC5BA → #26A8FF), 48px monospace code display
• Built ForgotPassword page matching auth theme - gradient background, white card, animated elements
• Built ResetPassword page as single component with 2-step internal flow:
  - Step 1: Enter and verify 6-digit code
  - Step 2: Create new password with show/hide toggles
• Updated token generation system - generate6DigitCode() function (100000-999999)
• Added verify-reset-code endpoint for code validation without password change
• Modified JWT auth endpoints to accept "code" instead of "token"
• Fixed routing issues - used window.location.href for reliable redirects
• Auto-login after successful password reset - redirects directly to dashboard

**3. UI/UX Improvements:**
• Changed code input background from green to white for cleaner appearance
• Fixed meal card overflow issue in recipes carousel - three dots menu now visible on last item
• Updated success messages - "Logging you in..." instead of "Redirecting to login"
• Improved redirect flow - immediate redirect from ForgotPassword to ResetPassword
