Prompt:

I’m building a nutrition app that runs inside a WebView. The Android wrapper listens for data via a JavaScript interface called NutriAIAndroid and a method named updateState(jsonString).

I need you to inject a NutriAIAndroid.updateState(JSON.stringify({...})) call every time the user interacts with the following core features, so that my Android code can collect and store state for personal push notifications.

Each updateState call should contain this JSON structure:

{
  "goal": "cutting" or "bulking",
  "caloriesTarget": number, 
  "caloriesEaten": number, 
  "mealsLoggedToday": number, 
  "weightTrend": "gaining" or "losing", 
  "streakDays": number, 
  "lastActiveDate": "YYYY-MM-DD", 
  "userName": string (if available)
}

👉 WHEN TO CALL IT:
	•	After a food item is logged (manual or by scanning)
	•	After a meal plan is generated
	•	After the user marks a meal as “completed” or “skipped”
	•	After scanning a recipe from ingredients/fridge
	•	After the user scans their physique / updates weight
	•	After checking body fat estimate
	•	After skipping or completing a day
	•	When streak or adherence is calculated

✅ Example:

NutriAIAndroid.updateState(JSON.stringify({
  goal: "cutting",
  caloriesTarget: 2200,
  caloriesEaten: 1700,
  mealsLoggedToday: 3,
  weightTrend: "losing",
  streakDays: 5,
  lastActiveDate: "2025-04-15",
  userName: "Adam"
}));

Please also call NutriAIAndroid.updateState(...) each time values change in the app UI (such as when the user updates their weight, goal, or meal log).

This is how the Android side keeps state in sync and uses it to schedule smart notifications. You don’t need to show anything to the user — just silently call this method after every key action.
